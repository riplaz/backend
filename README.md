Распределение обязанностей
Елисей — Routes, Server, Package
Routes — создание эндпоинтов. Определяют, по какому адресу и HTTP-методу поступает запрос и какой контроллер необходимо вызвать.
server.js — создание Express-приложения, подключение библиотек, middleware и маршрутов, запуск сервера.
package.json — настройки проекта, зависимости и команды запуска.
README.md — документация проекта, зависимости и команды запуска.

Глеб — Controllers
Принимает запросы от маршрутизаторов.
Получает данные из запроса.
Проверяет корректность входных данных.
Вызывает необходимые функции сервисов.
Возвращает ответы клиенту и HTTP-статусы.

Валера — Services
Пишет основную бизнес-логику сайта.
Реализует регистрацию и проверку паролей.
Реализует создание, редактирование и удаление идей.
Реализует голосование и комментарии.
Отвечает за работу с данными.
